Posicionamiento SEO y Sitemaps

Lección Asincrónica #2 · Tercera Parte

1. Posicionamiento SEO

El SEO (Search Engine Optimization) es el conjunto de técnicas para mejorar la visibilidad de un sitio web en los resultados orgánicos (no pagados) de buscadores como Google, Bing o DuckDuckGo.

Cuando alguien busca algo, el motor de búsqueda usa algoritmos para decidir qué páginas mostrar primero. El SEO busca alinear el sitio con esos criterios.

El 75% de los usuarios nunca pasa de la primera página de resultados. Los primeros 3 resultados concentran entre el 50–60% del tráfico total de una búsqueda.

Los tres pilares del SEO

On-Page Títulos, meta descriptions, encabezados (H1–H6), URLs amigables, contenido de calidad.
Off-Page Backlinks de calidad, menciones en redes, autoridad del dominio.
Técnico Velocidad, HTTPS, sitemap.xml, robots.txt, mobile-friendly, Core Web Vitals.

Buenas prácticas

  • Investigar palabras clave con Google Search Console, Semrush o Ahrefs.
  • Escribir un <title> único y descriptivo (50–60 caracteres) por página.
  • Incluir una meta description atractiva de 150–160 caracteres.
  • Usar un solo <h1> por página y estructurar el resto con H2, H3.
  • Optimizar imágenes: atributo alt, formato WebP, lazy loading.
  • Mantener la velocidad de carga por debajo de 2 segundos (PageSpeed Insights).
  • Diseño responsive / mobile-first.
  • Crear contenido de valor que otros quieran enlazar de forma natural.
  • Registrar el sitio en Google Search Console y Bing Webmaster Tools.

2. Sitemaps

Un sitemap es un archivo o página que lista todas las URLs de un sitio de forma organizada. Actúa como un índice que facilita a los robots de búsqueda (crawlers) descubrir y entender la estructura del contenido.

Analogía: un sitemap es como el directorio de un mall. Le dice a los visitantes (y robots) dónde está cada tienda (página) sin tener que recorrer todos los pasillos.

¿Por qué tener uno?

  • Indexación más rápida: los buscadores descubren páginas nuevas en horas, no semanas.
  • Mejor cobertura: páginas con pocos enlaces internos (huérfanas) también se indexan.
  • Priorización: indica qué páginas son más importantes y con qué frecuencia cambian.
  • Multimedia: Google tiene extensiones para indexar imágenes y videos.
  • Diagnóstico: Google Search Console muestra errores de indexación por sitemap.

Tipos de sitemap

Tipo Para quién Uso
XML Motores de búsqueda SEO técnico, indexación automática
HTML Usuarios Usabilidad, accesibilidad, navegación secundaria
XML Imágenes Google Images Indexar imágenes del sitio
XML Video Google Video Mejorar visibilidad de videos

Implementación paso a paso

Paso 1 — Crear el sitemap XML en la raíz del servidor:

<!-- sitemap.xml -->
<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">

  <url>
    <loc>https://miwebcr.com/</loc>
    <lastmod>2026-04-24</lastmod>
    <changefreq>weekly</changefreq>
    <priority>1.0</priority>
  </url>

  <url>
    <loc>https://miwebcr.com/productos</loc>
    <lastmod>2026-04-20</lastmod>
    <changefreq>daily</changefreq>
    <priority>0.8</priority>
  </url>

</urlset>

Paso 2 — Referenciar en robots.txt:

# robots.txt — raíz del servidor
User-agent: *
Disallow: /admin/
Sitemap: https://miwebcr.com/sitemap.xml

Paso 3 — Enviarlo a Google Search Console: ir a Sitemaps, ingresar la URL (sitemap.xml) y presionar "Enviar". Google mostrará cuántas URLs fueron indexadas.

Herramientas: en WordPress, Yoast SEO o Rank Math generan el sitemap automáticamente. Para sitios estáticos, xml-sitemaps.com permite generarlo ingresando la URL del dominio.
